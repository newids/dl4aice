부록 — 외워야 하는 코드 3단 분해

시험은 제한적 오픈북이지만, 아래 아홉 묶음은 찾아보지 않고 바로 써야 시간이 남습니다. 긴 코드를 통째로 외우지 않고 세 단계로 나눠 외웁니다.

3단 분해로 외우는 방법

  1. 1단 흐름

    블록 전체를 낱말 네다섯 개의 순서로 줄입니다. 먼저 이 순서만 소리 내어 말할 수 있게 합니다.

  2. 2단 줄

    순서의 낱말 하나를 코드 한두 줄로 바꿉니다. 주석의 번호가 1단의 순서와 같습니다.

  3. 3단 값

    문제마다 바뀌는 자리와 넣을 값을 따로 외웁니다. 나머지는 손대지 않는 고정 부분입니다.

연습 순서: 1단을 말한다 → 코드를 가리고 2단을 쓴다 → 문제 유형을 바꿔 3단 값만 갈아 끼운다. 각 묶음 끝의 가리고 떠올리기 질문으로 확인합니다.

묶음문항1단 흐름
A. 첫 셀 임포트문항 1텐서플로 → 넘파이·판다스 → 그래프 둘 → 사이킷런 넷 → 케라스 셋
B. 결측치 · 이상치 · 인코딩문항 4~6결측치 채우기 → IQR 경계 구하기 → 범위 안의 행만 남기기 → 인덱스 다시 매기기 → 원-핫 인코딩
C. 분리와 스케일링문항 7X·y 나누기 → 학습·평가 분리 → 스케일러 만들기 → 학습 데이터에 fit_transform → 평가 데이터에 transform
D. 머신러닝 모델 3줄문항 8~10모델 만들기 → fit → predict → 지표 출력
E. 딥러닝 모델 구성문항 11입력 → 은닉층 → Dropout → 은닉층 → 출력층
F. 컴파일 · 콜백 · 학습문항 11~12compile → EarlyStopping → ModelCheckpoint → fit
G. 학습 곡선문항 13loss 선 → val_loss 선 → 축 이름 → 범례 → show
H. 평가와 예측값 변환문항 14 앞부분evaluate → predict → 클래스로 변환 → 지표 출력
I. 새 입력 한 건 예측문항 14 뒷부분표로 만들기 → 같은 인코딩 → 컬럼 맞추기 → 같은 스케일러로 변환 → 예측

전체 순서도 한 줄로 외웁니다: 임포트 → 결·이·인 → 분·스 → 머신러닝 → 구·컴·학 → 곡선 → 평·예 (결측치·이상치·인코딩 / 분리·스케일링 / 구성·컴파일·학습 / 평가·예측).

앞 글자로 줄이면: 결 → 이 → 인 (채우고, 자르고, 숫자로 바꾼다)

2단 줄

# ① 결측치: 그 컬럼의 중앙값으로 채우고 다시 대입
df['age'] = df['age'].fillna(df['age'].median())

# ② 이상치: Q1, Q3, IQR 을 구한 뒤 경계 안의 행만 남김
q1 = df['monthly_fee'].quantile(0.25)
q3 = df['monthly_fee'].quantile(0.75)
iqr = q3 - q1
df = df[(df['monthly_fee'] >= q1 - 1.5 * iqr) & (df['monthly_fee'] <= q3 + 1.5 * iqr)]
df = df.reset_index(drop=True)

# ③ 인코딩: 문자열 컬럼을 0/1 컬럼으로
df = pd.get_dummies(df, columns=['contract'], dtype=int)

3단 값

바뀌는 자리넣을 값
채우는 값수치형 .median() 또는 .mean(), 범주형 .mode()[0]
결측 행 삭제지문이 삭제를 요구하면 df = df.dropna()
IQR 배수1.5 — 지문에 다른 값이 없으면 고정
인코딩 대상columns=[…]에 문자열 컬럼 이름
타깃이 문자열일 때LabelEncoder().fit_transform(df['target'])

고정 fillna 결과는 반드시 다시 대입합니다. 행을 지운 뒤에는 reset_index(drop=True)를 붙입니다. dtype=int를 주면 True/False가 아니라 0/1이 됩니다.

가리고 떠올리기
  1. IQR 하한과 상한을 구하는 식을 쓰십시오.
  2. 조건 두 개를 묶을 때 쓰는 연산자와 괄호의 위치를 말하십시오.

X = df.drop(columns=['churn'])

# ③ 스케일링: 학습 데이터로만 기준을 잡고, 평가 데이터는 변환만

X_test_scaled = scaler.transform(X_test)

stratify분류는 stratify=y, 회귀는 쓰지 않음
스케일러StandardScaler() / MinMaxScaler()

고정 random_state=42, 반환 변수 네 개의 순서, fit_transform은 학습 데이터에만 쓴다는 점은 바뀌지 않습니다.

  2. 은닉층
  3. Dropout

앞 글자로 줄이면: 입 → 은 → 드 → 은 → 출

2단 줄

# Sequential 방식: 빈 모델에 층을 순서대로 add
model = Sequential()
model.add(Input(shape=(X_train_scaled.shape[1],)))   # ① 입력: 특성 개수
model.add(Dense(64, activation='relu'))              # ② 은닉층
model.add(Dropout(0.3))                              # ③ Dropout
model.add(Dense(32, activation='relu'))              # ④ 은닉층
model.add(Dense(1, activation='sigmoid'))            # ⑤ 출력층

같은 모델을 함수형(Functional) 방식으로

inputs = Input(shape=(X_train_scaled.shape[1],))     # ① 입력
x = Dense(64, activation='relu')(inputs)             # ② 앞 층의 결과를 괄호로 넘김
x = Dropout(0.3)(x)                                  # ③
x = Dense(32, activation='relu')(x)                  # ④
outputs = Dense(1, activation='sigmoid')(x)          # ⑤ 출력층
model = Model(inputs=inputs, outputs=outputs)        # ⑥ 처음과 끝을 묶음

3단 값

바뀌는 자리넣을 값
출력층 — 이진분류Dense(1, activation='sigmoid')
출력층 — 다중분류Dense(클래스 수, activation='softmax')
출력층 — 회귀Dense(1) — 활성화 함수 없음
은닉층 노드 수, Dropout 비율지문의 숫자 그대로

고정 입력은 Input(shape=(특성 수,))이며 쉼표를 빼면 안 됩니다. 은닉층 활성화 함수는 'relu'입니다. 문제 유형이 바뀌어도 고치는 곳은 출력층 한 줄입니다.

                    validation_split=0.2, epochs=50, batch_size=32,

3단 값

바뀌는 자리넣을 값

loss — 회귀'mse', 지표는 metrics=['mae']
patience, epochs, batch_size지문의 숫자 그대로
검증 데이터validation_split=0.2 또는 validation_data=(X_val, y_val)

고정 monitor='val_loss', restore_best_weights=True, save_best_only=True, 저장 확장자 .keras, metrics와 callbacks는 대괄호 리스트라는 점은 바뀌지 않습니다. 분류 지표 이름은 'accuracy'로 풀어 씁니다.

new_df = pd.DataFrame([new_data])                                   # ① 딕셔너리를 대괄호로 감싸 1행 표로
new_df = pd.get_dummies(new_df, columns=['contract'], dtype=int)    # ② 학습 때와 같은 인코딩
new_df = new_df.reindex(columns=X.columns, fill_value=0)            # ③ 학습 때의 컬럼 구성과 순서로
new_scaled = scaler.transform(new_df)                               # ④ 이미 학습된 스케일러로 변환만
new_pred = model.predict(new_scaled)                                # ⑤ 예측
print(new_pred[0][0], int(new_pred[0][0] > 0.5))
