# AICE Associate 딥러닝 실전 교본

## [공지] AICE Associate 딥러닝 실전 교본 사이트 안내 및 학습 가이드

AICE Associate 실기 시험의 딥러닝 파트를 체계적으로 준비할 수 있는 무료 웹 교재를 공유합니다. 별도 설치 없이 브라우저에서 바로 실습할 수 있으며, 진도와 학습 기록은 사용 중인 브라우저에 자동 저장됩니다.

### 주요 제공 콘텐츠

* 이론 및 예제: 8개 챕터, 핵심 도해 46개, 실행 검증된 예제 코드
* 실전 연습: 챕터별 빈칸 채우기 실습 42문항, 14문항 CBT 모의고사 3회분
* 최종 정리: 시험 직전용 치트시트, 필수 암기 코드 부록

### 추천 학습 순서

1. 개념 학습 (Ch01~Ch08): 챕터를 순서대로 읽되, 도해를 먼저 파악한 뒤 본문을 읽으면 훨씬 빠르게 이해됩니다.
2. 챕터별 실습: 각 챕터 끝의 실습 셀에서 빈칸을 채우고 Shift+Enter로 바로 채점해 보세요. 오답 시 어떤 변수명이나 인자가 틀렸는지 바로 피드백해 줍니다.
3. 필수 코드 암기 (부록 A): 자주 쓰는 코드를 흐름·줄·값 3단계로 나누어 외웁니다. 코드를 가리고 직접 타이핑해 보며, 페이지 상단에 표시되는 복습 일자에 맞춰 반복해 보세요.
4. 실전 모의고사 (3회분): 90분 타이머를 켜고 실제 시험처럼 풀어봅니다. 채점 후 제공되는 파트별 분석을 통해 취약한 부분을 확인하고 해당 챕터를 복습합니다.
5. 시험 직전 마무리: 치트시트로 전체 흐름을 훑고, 오픈북 시험에 대비해 Ctrl+K 검색 기능으로 필요한 함수를 빠르게 찾는 연습을 해두세요.
