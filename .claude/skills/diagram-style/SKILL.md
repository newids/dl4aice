# 도해 스타일 시스템

모든 도해가 한 사람이 그린 것처럼 보여야 한다. 이 시스템을 벗어난 도해는 재작업 대상이다.

## 기술 스펙

- 순수 SVG, `viewBox="0 0 800 {H}"` (H는 내용에 맞게, 450 기본). 외부 폰트·이미지·CSS 참조 금지.
- 폰트: `font-family="'Pretendard', 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif"` (시스템 폴백 체인).
- 파일명 = 플레이스홀더 id (`ch03_dense-layer.svg`). 다르면 빌더가 매칭하지 못한다.
- 루트에 `<title>` 요소로 한국어 대체 텍스트를 넣는다 (접근성).

## 팔레트 (교육용 시맨틱 컬러)

| 토큰 | 값 | 용도 |
|------|-----|------|
| ink | `#1a2332` | 기본 텍스트, 테두리 |
| paper | `#ffffff` | 배경 (투명 금지 — e-book 배경과 분리) |
| primary | `#2563eb` | 핵심 개념, 현재 단계, 뉴런 활성 |
| primary-soft | `#dbeafe` | primary 요소의 면 채움 |
| accent | `#f59e0b` | 주의·강조 포인트 (챕터당 절제해서) |
| success | `#059669` | 정답 경로, 올바른 선택 |
| danger | `#dc2626` | 오류, 과적합, 잘못된 선택 |
| muted | `#94a3b8` | 비활성 요소, 보조선, 주석 |

색은 장식이 아니라 의미다: primary=지금 배우는 것, muted=맥락, danger=피할 것. 한 도해에 시맨틱 색 3개 이하.

## 타이포그래피

- 제목 20px bold(도해 상단 좌측), 노드 라벨 15px, 주석 12px muted. 11px 미만 금지.
- 텍스트는 최소한으로 — 문장이 필요하면 본문의 일이다. 라벨은 명사구로.
- 유니코드 아래첨자·수학 기호(w₁, Σ 등)는 렌더러에 따라 깨진다. ASCII(w1) 또는 `<tspan baseline-shift>` 로 표기한다.

## 레이아웃 규칙

- 여백: viewBox 가장자리에서 최소 24px. 요소 간 최소 16px.
- 흐름 방향: 좌→우 (파이프라인), 상→하 (계층). 혼용 금지.
- 화살표: `stroke-width="2"`, marker 삼각형 통일. 데이터 흐름은 실선, 참조·보조는 `stroke-dasharray="6 4"` 점선.
- 둥근 사각형 `rx="10"` 통일. 그림자·그라데이션 금지 — 인쇄·다크모드 대비 플랫 유지.

## 도해 유형별 구도

| 유형 | 구도 | 예 |
|------|------|-----|
| 구조도 | 좌→우 레이어 컬럼, 뉴런은 원(r=18), 연결선 muted | 신경망, Dense 레이어 |
| 파이프라인 | 좌→우 박스 체인 + 화살표, 현재 단계만 primary | 전처리→학습→평가 흐름 |
| 비교도 | 좌우 2패널 분할, 중앙 구분선, 좋음=success/나쁨=danger | 과적합 vs 적정 학습 |
| 판단 분기도 | 상→하 의사결정 트리, 질문은 마름모 | loss 함수 선택 |
| 그래프 개념도 | 축+곡선 개략도 (실데이터 아님을 주석) | 학습 곡선 해석 |

## 자기 검증 체크리스트 (제출 전)

- [ ] viewBox 있고 외부 참조 없음
- [ ] 파일명이 플레이스홀더 id와 일치
- [ ] 팔레트 외 색상 미사용, 시맨틱 색 3개 이하
- [ ] 텍스트 겹침·잘림 없음 (긴 한국어 라벨은 글자수 × 15px로 폭 추정)
- [ ] 한 도해 = 한 메시지
