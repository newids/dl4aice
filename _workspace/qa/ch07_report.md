**담당: chapter-writer** / **위치:** `chapters/ch07.md` L104

> sklearn 함수들은 1차원 라벨 배열을 기대하므로, 펴 두면 **불필요한 경고를 피할 수 있습니다.**

같은 교재의 문제집 Q4 해설(L462)은 **이미 정확한 근거**를 서술하고 있다:

> sklearn의 mse·mae·r2 함수 자체는 `(N, 1)`을 받아 주기 때문에 여기서는 값이 맞게 나옵니다. 문제는 그다음입니다.
> 잔차를 직접 계산하면 … `(N, N)` 행렬이 되고, `pd.DataFrame({...})`로 비교표를 만들면 `ValueError`가 납니다.

### M-2. 7.7의 `model.fit()` 재호출이 "이어 학습"이 되어 곡선 예시로 부적합

**담당: chapter-writer** / **위치:** `chapters/ch07.md` L417–419

```python
# 7.1의 model을 다시 학습시켜 history 객체를 받습니다
history = model.fit(X_train, y_train, epochs=30, ...)
```

Keras `fit`은 가중치를 초기화하지 않으므로, 이미 30 epoch 학습된 모델을 **30 epoch 더 이어서** 학습한다.
실측 결과 이 두 번째 `fit`의 곡선은 시작부터 이미 수렴 상태다:

```
연속학습 loss     첫 0.0379 → 끝 0.0141
연속학습 val_loss 첫 0.0188 → 끝 0.0104
```

거의 평탄한 저손실 곡선이 그려져, 이 절의 목적("점수가 낮은 원인이 학습 부족인지 과적합인지 한눈에 드러난다")을
예시가 뒷받침하지 못한다. 부수적으로 `model`의 상태가 바뀌므로, 독자가 7.7 실행 후 7.3을 다시 실행하면 앞의 수치와 달라진다.

## 11.3 저자 문의 회신 — 7.1 `loss 0.0812` 실측 확정

**결론: `0.0812`는 오류이며, run 4의 실측 loss는 `0.075`다. 정정이 필요하다.**

근거 1 — **run 4 지문 대조.** 1차 검수 로그에서 확률 배열 `[0.005 0.871 0.952 0.002 0.258]`(5개 숫자 지문)을

```
loss: 0.075 / accuracy: 0.9708
앞 5개 확률: [0.005 0.871 0.952 0.002 0.258]
TN: 63 / FP: 1 / FN: 4 / TP: 103
```

즉 본문이 단일 출처로 채택한 그 실행의 loss는 **0.075**다.
(`round(loss, 4)` 출력이므로 게재 형식은 `loss: 0.075`가 된다.)

근거 2 — **관측 대역 밖.** 7.1 설정 9회 실행의 loss 관측값:

| loss | accuracy |
|------|----------|
| 0.0531 | 0.9825 |
| 0.0575 | 0.9883 |
| 0.0642 | 0.9766 |
| 0.0659 | 0.9708 |
| 0.0670 | 0.9708 |
| 0.0696 | 0.9766 |
| 0.0750 | 0.9708 ← **run 4 (본문 단일 출처)** |
| 0.0755 | 0.9649 |
| 0.0758 | 0.9708 |

관측 대역은 **0.053 ~ 0.076**이며 `0.0812`는 **9/9 실행보다 높아 대역 밖**이다.
1차 리포트가 0.0812를 "재현 가능 범위"로 표현한 것은 당시 loss를 표로 정리하지 않은 채 내린
느슨한 판단이었고, 이번 실측으로 **대역 밖임이 확정**되었다. 이 점은 1차 리포트의 과소 판정으로 정정한다.

**"스탬프 병기만으로 충분한가"에 대한 판단: 불충분하다.** 이유는 세 가지다.

1. `0.0812`는 독자에게 **두 곳에서 노출**된다 — 본문 L78 출력 블록, `ch07_evaluate-predict.svg` L37.
   `verified` 스탬프는 HTML 주석이라 e-book 독자에게 보이지 않으므로 노출 지점의 오류가 그대로 남는다.
2. 본문 7.3이 **"7.1과 같은 실행에서 이어진 결과"** 라고 단일 출처를 명시 주장한다.
   loss 하나만 다른 실행 값이면 이 주장 자체가 거짓이 되어, H-1에서 요구한 단일 출처 규율이 깨진다.
3. 수정 비용이 **숫자 한 개 × 2파일**로 극히 낮다. 주석으로 우회할 근거가 없다.

→ **H-3으로 분류하고 본문·도해 정정을 요청한다.**
