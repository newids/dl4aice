# 한국어 재검증 기록 — humanize-korean 스킬 (epoko77-ai/im-not-ai v2.4.8)

## 방법
- 대상 34개 문서(교재 본문 8, 확인 문제 8, 이전 판 모의고사 2, 14문항 모의고사 JSON, 실습 문항 JSON, 스터디 발표 자료 11, 부록, 치트시트, Ch03 3.7절)에서 코드 블록·주석·표 구분선을 뺀 본문 약 41만 자를 추출했다.
- 스킬의 정량 점수 스크립트(`scripts/prepare_monolith_input.py --genre report`)를 문서마다 실행해 위험도, 경로 권고, 패턴 수, 어휘 점검 항목을 받았다.
- 스킬은 한 편의 글을 통째로 다시 쓰는 절차(진단 → 윤문 → 게이트)를 갖고 있지만, 이 교재는 코드·표·채점 규칙이 섞여 있어 통째 윤문은 하지 않았다. 스크립트가 짚은 문장만 스킬의 규칙(quick-rules)에 따라 고쳤다.

## 고친 곳 (36곳)
- 짚다(7): "미리 짚어 둡니다" → "말해 둡니다", "한 줄만 짚습니다" → "다룹니다", "잘못 짚는 것" → "0을 1로 잘못 판정하는 것"(2곳), "짚어 내는" → "찾아 내는", "되짚으십시오" → "다시 확인하십시오", "짚어 두면" → "알아 두면"
- 매끄럽게(2): "넘파이 연산이 매끄럽게 이어집니다" → "문제없이 이어집니다"
- 가르다·갈리다(4): "두 함수를 가르는 결정적 차이" → "두 함수의 결정적 차이", "이름이 갈립니다" → "달라집니다", "즉시 갈립니다" → "바로 구분됩니다", "완전히 갈립니다" → "달라집니다"
- 그 밖의 어휘(5): "보시는 편이 좋습니다" → "보십시오", "깊이 파고들지 않고" → "자세히 다루지 않고", "차이를 만듭니다" → "달라집니다"(2곳), "되풀이합니다" → "반복합니다"
- 분열문(9): 예) "중요한 것은 개수가 아니라 비중입니다" → "문항 개수보다 비중이 중요합니다", "필요한 것은 임계값 판정입니다" → "임계값 판정이 필요합니다"
- "~이유입니다."(7): 예) "이 교재가 딥러닝에 집중하는 이유입니다" → "그래서 이 교재는 딥러닝에 집중합니다"
- 위 수정에 따른 문장 호응 보정(2)

## 적용하지 않은 규칙과 이유
- E-1(문단마다 100자 넘는 문장 만들기): 수험서는 짧은 문장이 읽기 쉽고, `korean-proofreading` 기준(한 문장에 내용 셋 이상이면 나눈다)과 반대 방향이다.
- E-2(같은 종결어미 연속 변주): 본문은 "~합니다" 경어체로 통일하는 것이 이 교재의 문체 규칙이다.
- C-2(불릿을 산문으로), J-1(본문 볼드 제거), C-10(콜론 부제 제목): 교재·발표 자료의 조판 형식이다.
- C-11(연결어미 뒤 쉼표): 스킬 스스로 밀도만으로는 사람 글과 구별되지 않는다고 밝혔고, 점수 스크립트도 경고를 내지 않았다.

## 남겨 둔 어휘 점검 항목
- "대괄호를 한 겹만"(모의고사 JSON): 대괄호 개수를 가리키는 실제 뜻
- "두 무리를 가르는 선"(Ch03 3.7절): 점 무리를 나누는 경계선이라는 실제 뜻
- "여러 층에"(발표 자료 3회): 신경망의 층
- "편이 안전합니다"(문서당 1회씩), "문법이 달라질 수 있으므로", "갈래": 조건부 항목이고 반복되지 않음
