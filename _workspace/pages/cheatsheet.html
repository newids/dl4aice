시험장 직전 10분 치트시트

시험 시작 전 마지막 10분에 위에서 아래로 한 번 훑고, 시험 중에는 막힐 때마다 이 페이지로 돌아오십시오. 유형별 출력층·loss, 빈출 에러 5가지의 10초 해결 코드, 1~14번 표준 변수명과 첫 셀 임포트 블록, 신규 샘플 예측 4줄 공식, 90분 시간 배분과 제출 전 점검만 한 장에 모았습니다. 인쇄(A4)하면 그대로 한 장짜리 시트가 됩니다.

Functional API (같은 모델)

inputs = Input(shape=(X_train_scaled.shape[1],))

x = Dense(32, activation='relu')(x)
outputs = Dense(1, activation='sigmoid')(x)
model = Model(inputs=inputs, outputs=outputs)
model.compile(optimizer='adam',
              loss='binary_crossentropy',
              metrics=['accuracy'])

② 시험장 빈출 에러 메시지 5선

메시지는 TensorFlow 2.21 / Keras 3.15 / pandas 3 / scikit-learn 1.9 에서 실제로 재현한 원문입니다(길면 …로 줄임). 구버전 환경은 문구가 조금 다를 수 있으나 원인과 해결은 같습니다.

1Shape mismatch

ValueError: Input 0 with name 'None' of layer 'dense' is incompatible with the layer: expected axis -1 of input shape to have value 12, but received input with shape (None, 13)

ValueError: Arguments `target` and `output` must have the same rank (ndim). Received: target.shape=(None,), output.shape=(None, 3)

ValueError: Per-column arrays must each be 1-dimensional

원인 위부터 순서대로: Input(shape) 숫자와 실제 열 수가 다름 / 정수 라벨(N,)에 categorical_crossentropy (원-핫이면 반대로 sparse 오류) / predict 결과 (N,1)을 그대로 표에 넣음.

10초 해결 코드

model.add(Input(shape=(X_train_scaled.shape[1],)))
loss='sparse_categorical_crossentropy'   # 정수 라벨
pd.DataFrame({'actual': y_test, 'pred': pred.flatten()})

2Unrecognized keyword

ValueError: Unrecognized keyword arguments passed to Dense: {'activaton': 'relu'}

ValueError: Argument(s) not recognized: {'lr': 0.001}

TypeError: Trainer.compile() got an unexpected keyword argument 'metric'. Did you mean 'metrics'?

원인 인자 이름 오타, 또는 Keras 3에서 사라진 옛 이름(lr 대신 learning_rate). 메시지의 중괄호 안에 틀린 이름이 그대로 적혀 있습니다.

4NaN loss

4/4 - 1s - 126ms/step - accuracy: 0.6100 - loss: nan

원인 오류 없이 학습만 망가집니다. y 또는 X에 결측치(NaN)나 inf가 남았거나, 스케일링 없이 값이 매우 커서 발산한 경우입니다. 한 번 nan이 되면 이후 epoch에서도 회복되지 않습니다. 입력 X의 NaN은 relu에 가려 겉으로 안 드러나기도 하니 y까지 함께 확인하십시오.

10초 해결 코드

print(df.isnull().sum())
df = df.dropna()   # 또는 fillna(중앙값)
print(np.isfinite(X_train_scaled).all())

5metric 이름 오류

KeyError: 'val_acc' (history.history['val_acc'])

UserWarning: Early stopping conditioned on metric `val_acc` which is not available. Available metrics are: accuracy,loss,val_accuracy,val_loss

원인 metrics=['accuracy']로 컴파일하면 기록 이름은 accuracy/val_accuracy입니다(acc 아님). val_로 시작하는 값은 validation_split(또는 validation_data)이 있어야 생깁니다.

신규 샘플 예측(유형 14) 4줄 공식

new_df = pd.get_dummies(pd.DataFrame([new_data]))
new_df = new_df.reindex(columns=X.columns, fill_value=0)
new_scaled = scaler.transform(new_df)

이진은 (new_pred > 0.5).astype(int), 다중은 np.argmax(new_pred, axis=1), 회귀는 new_pred.flatten().

신규 데이터에는 절대 fit하지 않는다. scaler.fit_transform(new_df)는 샘플 한 건으로 평균·표준편차를 새로 계산하므로 값이 전부 0이 됩니다. 학습 때 만든 scaler로 transform만 하십시오. reindex(columns=X.columns, fill_value=0)는 학습 때와 같은 열 순서·개수를 맞추는 핵심 줄입니다.
