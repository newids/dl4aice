## 오류 정정 읽는 순서

1. 지문에서 요구 조건을 먼저 읽습니다(변수 이름, 학습 데이터로만 fit, 검증 데이터로 계산 등).

## 자세히 보는 문항: Q9 스케일링 정정 (6점)

주어진 코드:

```python

X_train_scaled = scaler.fit_transform(X_valid)
X_valid_scaled = scaler.fit_transform(X_valid)
print(round(np.max(X_valid_scaled), 2))

답안9 = 0
```

고칠 곳 세 곳:
- `RobustScalar`는 없는 이름입니다. `RobustScaler`입니다(`import`와 호출 두 곳).
- `fit_transform(X_valid)`로 학습하는 줄은 `fit_transform(X_train)`이어야 합니다.
- 검증 데이터에는 `transform`만 씁니다. `fit_transform`은 스케일러를 새로 학습시킵니다.

고친 코드를 실행하면 3.53이 출력되고, `답안9 = 3.53`으로 바꿉니다. `RobustScaler`는 중앙값을 빼고 IQR로 나누므로 이상치의 영향이 작습니다.

## 자세히 보는 문항: Q13 딥러닝 회귀 모델 (14점)

층 구성은 글로 주어집니다.

`입력(특성 수) → Dense 64 (selu) → Dropout 0.1 → Dense 32 (selu) → Dense 16 (selu) → 출력 Dense 1 (linear)`

```python
model = Sequential([
    Input(shape=(X_train_scaled.shape[1],)),
    Dense(64, activation='selu'),
    Dropout(0.1),
    Dense(32, activation='selu'),
    Dense(16, activation='selu'),
    Dense(1, activation='linear'),
])
model.summary()
model.compile(optimizer='adam', loss='mse', metrics=['mae'])
es = EarlyStopping(monitor='val_loss', patience=5)
history = model.fit(X_train_scaled, y_train,
                    validation_data=(X_valid_scaled, y_valid),
                    epochs=30, batch_size=32, callbacks=[es], verbose=0)
```

- `summary()` 출력의 파라미터 수는 640, 0, 2,080, 528, 17이고 합계는 3,265입니다. 입력 특성이 9개라 첫 층은 9 x 64 + 64 = 640입니다.

## Q13에서 자주 틀리는 곳과 Q14 학습 곡선

Q13에서 자주 틀리는 곳:
- 은닉층 활성화 함수를 지문의 `selu` 대신 습관으로 `relu`로 씁니다.
- 스케일링 전의 `X_train`, `X_valid`를 넣습니다. 딥러닝에는 스케일링한 데이터를 씁니다.
- `es`를 만들고 `callbacks=[es]`를 빠뜨리면 조기 종료가 적용되지 않습니다.
- 지문에 없는 `restore_best_weights` 같은 인자를 추가하면 조건과 달라집니다.

Q14는 빈칸 문항입니다. 첫 줄의 `print`가 출력하는 키 목록을 보고 고릅니다.

```
['loss', 'mae', 'val_loss', 'val_mae']
```

- 14-1은 학습 손실 `loss`, 14-2는 검증 손실 `val_loss`, 14-3은 `plt.xlabel`입니다.
- y축 이름이 MSE이므로 지표인 `mae`, `val_mae`가 아니라 `loss` 계열 키를 씁니다.

## 함께 풀기 2 — 답과 이유 (Q12)

- `sklearn.metric`은 없는 모듈입니다. `sklearn.metrics`이고 `ModuleNotFoundError`가 납니다.
- `dt_model.predict(X_train)`은 `X_valid`로 바꿉니다. 검증 성능을 구하므로 검증 특성으로 예측합니다.
- `mean_absolute_error(y_train, rf_pred)`의 정답은 `y_valid`입니다. 예측에 쓴 데이터의 정답이어야 하고, `y_train`은 행 개수가 달라 오류가 납니다.

- 분류의 정확도처럼 큰 쪽을 고르면 반대로 답하게 됩니다.
