## 모의고사 1회와 달라진 점

| 항목 | 모의고사 1회 (이진분류) | 모의고사 2회 (다중분류) |
|---|---|---|
| 타깃 | `churn` 0/1 | 문자열을 `LabelEncoder`로 정수 0/1/2 |
| 출력층 | `Dense(1, activation='sigmoid')` | `Dense(n_classes, activation='softmax')` |
| 손실 함수 | `binary_crossentropy` | `sparse_categorical_crossentropy` |
| metrics | `accuracy` | `accuracy` |
| 비교 지표 | accuracy, f1 | accuracy, `average='macro'` F1 |
| 예측 변환 | `pred > 0.5` | `np.argmax(pred, axis=1)`, `le.inverse_transform` |
| stratify | `stratify=y` (70:30) | `stratify=y` (3클래스 비율 유지) |
| 스케일러 / API | `StandardScaler` / Sequential | `MinMaxScaler` / Functional |

라벨을 원-핫으로 만들면 `categorical_crossentropy`를 씁니다. 출력층은 같고 손실 이름만 바뀝니다.

## 자세히 보는 문항: Q5 이상치 제거와 누수 컬럼 삭제

```python
q1 = df['vibration'].quantile(0.25)
q3 = df['vibration'].quantile(0.75)
iqr = q3 - q1
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr
print('상한 초과 개수:', (df['vibration'] > upper).sum())

df = df[(df['vibration'] >= lower) & (df['vibration'] <= upper)]
df = df.drop(columns=['rul_days'])
print(df.shape)   # 상한 초과 54, (3946, 9)
```

채점에서 보는 것: `q1`, `q3`, 하한 = `q1 - 1.5 * iqr` / 상한 이하만 남기는 행 필터 / `rul_days` 컬럼 삭제

자주 틀리는 답:
- `q3`를 중앙값(50%)으로 계산, 상한 자리에 하한 변수를 사용(거의 모든 행이 삭제됨)
- 누수 컬럼 `rul_days`가 아니라 다른 컬럼을 삭제. `rul_days`는 불량 이후에 계산되는 값이라 남기면 점수가 비정상적으로 높아집니다.

## 자세히 보는 문항: Q11 모델 설계와 compile

n_classes = len(le.classes_)

## 함께 풀기 — 답과 이유 (Q10)

- `LGBMClassifier`: 분류 문제이므로 `Classifier`로 끝나는 클래스를 씁니다.
- `verbose=-1`: 지문이 학습 로그가 출력되지 않도록 -1을 지시했습니다. 1로 두면 로그가 출력됩니다.
- `predict(X_test_scaled)`: 학습 입력과 같은 스케일링된 평가 특성으로 예측합니다. 스케일링하지 않은 `X_test`는 오답입니다.
- `average='macro'` 두 칸: 3클래스 이상에서는 `average`를 지정해야 하고, 문항은 `macro`를 지시했습니다. `weighted`는 오답입니다.
- macro F1은 클래스별 F1을 같은 비중으로 평균하므로 소수 클래스에서 약하면 값이 내려갑니다.

## 함께 풀기 — 답과 이유 (Q14)

- `evaluate(X_test_scaled, y_test, verbose=0)`: 스케일링된 평가 데이터를 넣습니다.
- `np.argmax(pred, axis=1)`: `pred`는 (N, 3) 확률이고 행마다 가장 큰 위치를 고릅니다. 다중분류는 임계값 0.5를 쓰지 않습니다.
- `reindex(columns=X.columns, fill_value=0)`: 학습 때 12개 컬럼의 순서와 개수로 맞추고 없는 더미는 0입니다.
- `scaler.transform(new_df)`: 학습 때 만든 `scaler`를 재사용하며 `fit`하지 않습니다.
- `np.argmax(new_pred, axis=1)[0]`: (1, 3) 확률에서 클래스 번호 하나를 얻습니다.
- `le.inverse_transform`: 번호를 `normal`, `overheat`, `wear` 이름으로 되돌립니다.

## 정리

- 문자열 타깃은 `LabelEncoder`로 정수 라벨을 만들고, `le`를 보관했다가 `inverse_transform`으로 이름을 복원합니다.
- 다중분류는 `Dense(n_classes, softmax)`, 정수 라벨이면 `sparse_categorical_crossentropy`입니다. 원-핫 라벨이면 `categorical_crossentropy`입니다.
- 예측은 `np.argmax(pred, axis=1)`입니다. 임계값 0.5는 이진분류용입니다.
- `rul_days`처럼 불량 이후에 산출되는 컬럼은 타깃 누수이므로 Q5에서 삭제합니다.
- 클래스가 불균형하므로 `stratify=y`를 쓰고, accuracy와 함께 macro F1을 봅니다.
- 신규 샘플은 `reindex`, `scaler.transform`, `predict`, `argmax`, `inverse_transform` 순서입니다.

**Q1.** 타깃을 원-핫으로 바꿔서 `categorical_crossentropy`를 써도 됩니까?
답: 출력층은 같고 손실 이름만 바뀌므로 짝만 맞으면 됩니다. 다만 이 회차의 Q6은 `LabelEncoder`를 지시하므로 정수 라벨 경로로 `sparse_categorical_crossentropy`를 씁니다.

**Q2.** `LabelEncoder` 번호가 왜 normal, wear, overheat 순서가 아닙니까?

**Q3.** Q5에서 이상치를 제거하지 않고 `clip`으로 값을 제한해도 됩니까?
답: 실무에서는 행을 보존하므로 `clip`도 많이 씁니다. 그러나 이 문항은 "제거"를 지시했으므로 불리언 조건으로 걸러 `df`에 재대입합니다. 문항이 요구한 방식을 따르는 것이 우선입니다.
