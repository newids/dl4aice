## 빈칸은 주변 코드에서 찾습니다 (4분)

빈칸 문항은 지문과 코드에 단서가 이미 있습니다. 다음 순서로 읽습니다.

1. 지문의 설명 문장에서 하려는 일을 찾습니다. 예: "1행 2열", "예약 건수를 막대로", "분포를 나누어 히스토그램으로".

4. `답안N`에는 빈칸에 넣은 이름을 따옴표로 감싸 문자열로 저장합니다. 빈칸과 `답안N`이 서로 일치해야 합니다.

## 자세히 보는 문항: Q5 IQR 이상치 제거 (빈칸 2개)

```python
q1 = data['lead_days'].___(0.25)  # blank5-1
q3 = data['lead_days'].___(0.75)  # blank5-1
iqr = q3 - q1
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr
outlier_idx = data[(data['lead_days'] < lower) | (data['lead_days'] > upper)].index
data_temp = data.drop(outlier_idx).drop('booking_id', axis=1).___(drop=True)  # blank5-2
print(len(outlier_idx))
print(data_temp.shape)
```

모범 답안: `답안5_1 = 'quantile'`, `답안5_2 = 'reset_index'`. 출력은 `106`, `(2894, 11)`입니다.

- 인자가 0.25, 0.75이므로 분위수를 구하는 `quantile`입니다. 줄 이름 `q1`, `q3`도 단서입니다.
- `iqr`, `lower`, `upper`는 이미 완성된 줄이므로 그대로 읽고 `outlier_idx`가 어디서 만들어지는지 확인합니다.
- `reset_index(drop=True)`는 행을 지운 뒤 인덱스를 0부터 다시 매깁니다. `drop=True`가 없으면 기존 인덱스가 `index` 열로 남습니다.
- 결측치는 `quantile`이 제외하고 비교 결과가 False이므로 이 단계에서 삭제되지 않습니다.

## 자세히 보는 문항: Q8 계층 분리 70:30

```python
X = data_preset.drop('booking_status', axis=1)
y = data_preset['booking_status']
X_train, X_valid, y_train, y_valid = train_test_split(
    X, y, test_size=0.3, stratify=y, random_state=42)
print(X_train.shape, X_valid.shape)
# (1905, 16) (817, 16)
```

- 70:30이므로 `test_size=0.3`입니다. 이 시험지는 검증용 데이터를 `valid`라고 부릅니다.
- 타깃이 Kept 약 65%, Canceled 약 35%로 불균형이므로 `stratify=y`로 두 집합의 클래스 비율을 원래대로 맞춥니다.
- 반환값 순서는 `X_train, X_valid, y_train, y_valid`입니다. `X_train, y_train, ...` 순서로 받으면 엉뚱한 데이터가 들어갑니다.
- `stratify`에 `X`를 넘기지 않고 `y`를 넘깁니다.
- `X`에 타깃 열이 남아 있으면 모델이 정답을 보고 학습하여 성능이 비정상적으로 높아집니다.

## 자세히 보는 문항: Q10 GridSearchCV 두 개

```python
param_dt = {'max_depth': [3, 6], 'min_samples_leaf': [5, 20]}
gs_dt = GridSearchCV(DecisionTreeClassifier(random_state=42), param_dt, cv=3)
gs_dt.fit(X_train_scaled, y_train)

print(gs_rf.best_estimator_)
```

- 탐색 값의 조합은 모델마다 2 x 2 = 4개이고, 학습용 데이터만 3등분해 교차 검증합니다.
- 탐색 값은 `{'이름': [값, 값]}` 딕셔너리이고 이름은 문자열입니다.
- 지문에 없는 인자(`n_jobs`, `scoring` 등)는 넣지 않습니다.
- 탐색과 학습에는 `X_train_scaled`, `y_train`만 씁니다. `X_valid_scaled`는 Q12에서 처음 씁니다.
- `gs_dt`와 `gs_rf`의 이름을 서로 바꾸어 저장하지 않도록 두 블록을 따로 확인합니다.

## 함께 풀기 — 답과 이유 (Q13)

- `le.fit_transform(y_train)`: 학습용으로 변환 규칙을 만들면서 변환합니다.
- `le.transform(y_valid)`: 검증용은 같은 규칙을 적용만 합니다. `fit`을 다시 하지 않습니다.
- `activation='relu'` 두 곳: 지문의 층 구성에 Dense 32와 16이 relu라고 적혀 있습니다.
- `activation='sigmoid'`: 출력 노드 1개에서 0~1 확률 하나를 내므로 이진분류입니다.
- `loss='binary_crossentropy'`: 이진분류의 손실 함수입니다. 회귀의 `mse`, 다중분류의 `categorical` 계열이 아닙니다.
- `patience=5`: 지문이 검증 손실이 개선되지 않아도 5 epoch까지 기다리라고 안내합니다.
- 이 모델의 확률은 Kept일 확률입니다. `LabelEncoder`가 Kept에 1을 주었기 때문입니다.
