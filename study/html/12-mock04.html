자세히 보는 문항: Q13 딥러닝 회귀 모델 (14점)

층 구성은 글로 주어집니다.

입력(특성 수) → Dense 64 (selu) → Dropout 0.1 → Dense 32 (selu) → Dense 16 (selu) → 출력 Dense 1 (linear)

model = Sequential([
    Input(shape=(X_train_scaled.shape[1],)),
    Dense(64, activation='selu'),
    Dropout(0.1),
    Dense(32, activation='selu'),
    Dense(16, activation='selu'),
    Dense(1, activation='linear'),
])
model.summary()
model.compile(optimizer='adam', loss='mse', metrics=['mae'])
es = EarlyStopping(monitor='val_loss', patience=5)
history = model.fit(X_train_scaled, y_train,
                    validation_data=(X_valid_scaled, y_valid),
                    epochs=30, batch_size=32, callbacks=[es], verbose=0)
  • summary() 출력의 파라미터 수는 640, 0, 2,080, 528, 17이고 합계는 3,265입니다. 입력 특성이 9개라 첫 층은 9 x 64 + 64 = 640입니다.

주어진 코드에서 고칠 곳을 참가자가 먼저 찾습니다. 네 줄이 틀렸습니다.

from sklearn.metric import mean_absolute_error

dt_pred = dt_model.predict(X_train)
rf_pred = rf_model.predict(X_valid)

dt_mae = mean_absolute_error(y_valid, dt_pred)
rf_mae = mean_absolute_error(y_train, rf_pred)

print('DecisionTree MAE:', round(dt_mae, 3))
print('RandomForest MAE:', round(rf_mae, 3))

답안12 = ''

조건: 예측값은 dt_pred, rf_pred, MAE는 dt_mae, rf_mae에 저장하고 모두 검증 데이터(X_valid, y_valid)로 계산합니다. 지문의 출력은 DecisionTree MAE: 5.598, RandomForest MAE: 4.353입니다.

함께 풀기 2 — 답과 이유 (Q12)

  • sklearn.metric은 없는 모듈입니다. sklearn.metrics이고 ModuleNotFoundError가 납니다.
  • dt_model.predict(X_train)은 X_valid로 바꿉니다. 검증 성능을 구하므로 검증 특성으로 예측합니다.
  • mean_absolute_error(y_train, rf_pred)의 정답은 y_valid입니다. 예측에 쓴 데이터의 정답이어야 하고, y_train은 행 개수가 달라 오류가 납니다.
  • 고친 뒤 MAE는 5.598과 4.353이고 작을수록 좋은 지표이므로 답안12 = 'RandomForest'입니다. MAE는 배달 시간과 같은 단위(분)라서 평균적으로 몇 분 틀리는지로 읽습니다.
  • 분류의 정확도처럼 큰 쪽을 고르면 반대로 답하게 됩니다.

정리

  • 공식 샘플 형식은 데이터 분석 20점, 데이터 전처리 30점, AI 모델링 50점이고, 문항 유형은 코드 작성, 오류 정정, 빈칸 채우기입니다.
  • 답안N에는 출력에서 읽은 값이나 빈칸에 넣은 말을 지문이 정한 자료형으로 저장합니다.
  • 오류 정정은 지문의 조건과 한 줄씩 대조하고, 없는 이름, 학습용과 검증용 데이터 혼동, fit_transform과 transform 혼동, 정렬 방향을 확인합니다.
  • 스케일러는 학습 데이터로만 fit하고 검증 데이터에는 transform만 씁니다.
  • 회귀 딥러닝은 출력 Dense 1(linear), 손실 mse, 지표 mae이며, 학습 곡선의 키는 loss, val_loss입니다.
  • 층 구성이 글로 주어지므로 활성화 함수와 노드 수를 지문대로 옮깁니다.

Q1. 검증 데이터 이름이 X_test가 아니라 X_valid인 이유는 무엇입니까? 답: 공식 샘플 문항의 표기를 따른 것이고, 이 시험은 검증 데이터로 성능을 비교합니다. 변수 이름은 지문이 정한 대로 씁니다.

Q2. Q9에서 fit_transform을 검증 데이터에도 쓰면 어떻게 됩니까? 답: 스케일러가 검증 데이터로 중앙값과 IQR을 새로 계산하므로 학습 데이터와 기준이 달라집니다. 검증 데이터에는 학습 데이터로 학습한 scaler의 transform만 씁니다.

Q3. Q9에서 일부만 고치면 어떻게 됩니까? 답: 코드가 실행되더라도 출력값이 달라져 답안9가 틀립니다. 클래스 이름 철자, fit_transform(X_train), transform(X_valid) 세 곳을 모두 고칩니다.
