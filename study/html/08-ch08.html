8.1 유형별로 바뀌는 곳 (2분)

  • 전처리, 은닉층, Dropout, EarlyStopping, 학습 곡선은 세 유형에서 같습니다.
  • 코드에서 바꾸는 곳은 네 곳입니다: 출력층, loss, metrics, 예측 변환.
  • metrics는 회귀에서만 바뀌므로 분류끼리 비교하면 세 곳입니다.

  • 값 2개는 이진, 정수 3개 이상은 다중, 계속 다른 실수는 회귀입니다.

자주 틀리는 지점 (1) 출력층과 loss의 짝 (1분)

  • loss만 바꾸고 출력층을 그대로 두는 실수가 가장 흔합니다. 반대로 출력층만 바꾸고 loss를 두는 경우도 같습니다. 두 줄은 한 쌍입니다.
  • 라벨이 정수면 sparse_categorical_crossentropy, 원-핫이면 categorical_crossentropy입니다. 출력층은 둘 다 Dense(K, 'softmax')입니다.
  • 회귀 출력층에 sigmoid를 붙이면 예측이 1을 넘지 못해 r2가 크게 음수가 됩니다.
  • 회귀에는 stratify를 쓰지 않습니다.

8.2 템플릿 A: 이진분류 end-to-end (3분)

  • 8단계: 로딩, 탐색, 결측 처리, 인코딩과 분리와 스케일링, 구성, 컴파일, 학습, 평가.
  • 시험에서는 로딩 블록만 df = pd.read_csv('data.csv')로 바꿉니다.
  • 교재 예시에서 df.shape는 (1000, 5)인데 입력 특성 수는 6입니다. get_dummies가 범주 컬럼 하나를 세 컬럼으로 펼치기 때문이므로 Input(shape=(X_train_scaled.shape[1],))로 받습니다.

8.5 오류 대처 방법: 네 가지 증상 (3분)

8.5 메시지 키워드로 원인 좁히기 (2분)

  • 메시지가 길어도 키워드 한 개를 먼저 찾습니다.
  • incompatible이 보이면 입력 shape 문제입니다. 같은 줄의 숫자 두 개, to have value 10(모델이 기대한 값)과 (None, 13)(실제 입력)를 비교합니다.
  • label value가 보이면 라벨과 출력층 문제입니다. 예: Received a label value of 2 which is outside the valid range of [0, 1)는 클래스 3개에 Dense(1)을 쓴 경우입니다.
  • nan은 오류 메시지가 나지 않습니다. 학습 출력의 loss: nan을 직접 보고 알아챕니다.
  • 교재의 오류 문구는 Keras 3 기준이며 Keras 2에서는 표현이 다르지만, 숫자 두 개를 비교하는 방법은 같습니다.

8.5 학습이 안 될 때 자가 진단 4줄 (3분)

print('1. 입력 결측:', np.isnan(X_train_scaled).sum())
print('2. 입력 범위:', X_train_scaled.min().round(2), '~', X_train_scaled.max().round(2))
print('3. 라벨 분포:', np.bincount(y_train))
print('4. 출력층:', model.layers[-1].units, model.layers[-1].activation.__name__)
  • 1번이 0이 아니면 결측 처리를 빠뜨린 것입니다.
  • 2번 범위가 0 ~ 800처럼 넓으면 스케일링하지 않은 배열을 넣은 것입니다.
  • 3번이 심하게 치우쳤으면 정확도가 의미 없습니다.
  • 4번은 이진 1 sigmoid, 다중 K softmax, 회귀 1 linear여야 합니다.
  • 모델을 만든 직후 model.summary()를 출력해 두면 shape 관련 오류를 미리 알아챌 수 있습니다.

자주 틀리는 지점 (2) 오류를 만났을 때 (1분)

  • 오류가 나면 코드를 처음부터 다시 쓰지 않고 메시지의 키워드를 찾습니다.
  • 오류를 보고 epochs나 batch_size를 조정하지 않습니다. 학습 설정과 무관한 오류가 많습니다.
  • 실행이 되었다고 맞은 것이 아닙니다. 회귀에서는 예측값 범위를 실제값 범위와 비교합니다.
  • r2가 -4처럼 크게 음수이면 코드 오류를 먼저 의심합니다.
  • 스케일러를 두 번 fit한 흔적이 없는지 재실행으로 확인합니다.

함께 풀기 — 답과 이유 (2분)

문제 1 (ch08-q2)

n_classes = len(np.unique(y_train))
model.add(Dense(n_classes, activation='softmax'))
loss='sparse_categorical_crossentropy'
y_pred = np.argmax(pred, axis=1)
  • 바뀌는 곳은 출력층, loss, 예측 변환입니다. metrics=['accuracy']는 그대로입니다. predict shape (54, 3)과 행 합 1.0으로 교체를 점검합니다.

문제 2 (ch08-q4)

n_classes = len(np.unique(y_train))
model.add(Dense(n_classes, activation='softmax'))
print('출력 shape:', model.output_shape)
  • 출력 노드가 1개이면 허용 라벨 범위가 [0, 1)이라 라벨 1, 2가 범위를 벗어납니다. 출력층을 고쳐야 하고 loss는 그대로 둡니다.

정리

  • 유형이 바뀌어도 바꾸는 곳은 출력층, loss, metrics, 예측 변환 네 곳이고 나머지 골격은 같습니다.
  • 출력층과 loss는 짝으로 바꾸고, predict 다음 줄에는 유형에 맞는 변환 한 줄을 둡니다.
  • 오류는 incompatible, label value, nan 같은 키워드로 좁히고, 자가 진단 4줄을 돌립니다.
  • 단계별 셀 분리와 셀 끝 print()가 부분 점수를 지키는 기본 방식입니다.
  • 마지막 10분은 새 코드를 쓰지 않고 재실행과 지시 대조에 씁니다.

예상 질문과 답 (1)

Q1. 다중분류 라벨이 문자열 클래스이면 어떻게 합니까? 답: 교재 템플릿은 정수 라벨을 전제로 하므로, 라벨 인코딩으로 정수로 바꾼 뒤 sparse_categorical_crossentropy를 씁니다. 예측 뒤에는 np.argmax로 번호를 얻고 inverse_transform으로 원래 이름으로 되돌립니다.

Q2. 입력 특성 수가 헷갈릴 때 Input(shape=)에 숫자를 직접 써도 됩니까? 답: 가능하지만 원-핫 인코딩 뒤의 특성 수는 사람이 세다가 틀리기 쉽습니다. X_train_scaled.shape[1]로 받으면 shape 불일치 오류를 처음부터 막을 수 있습니다.

Q3. 정확도가 0.7 정도밖에 안 나오는데 코드가 틀린 것입니까? 답: 교재의 합성 이탈 데이터는 원래 어려워 0.7대가 나옵니다. 채점은 점수의 절대값보다 지시한 절차를 지켰는지를 본다고 교재는 설명하므로, 자가 진단 4줄로 코드 오류가 아닌지만 확인합니다.

예상 질문과 답 (2)

Q4. 한 셀에 몰아 쓰면 안 되는 이유가 무엇입니까? 답: 모델 구성에서 오류가 나면 그 셀 전체가 실행되지 않아 앞 단계의 출력도 남지 않습니다. 단계마다 셀을 나누면 오류가 나도 앞 단계 결과가 화면에 남습니다.

Q5. epochs=100으로 걸어 두고 기다려도 됩니까? 답: 학습 구간이 가장 시간을 잃기 쉬운 곳입니다. 먼저 epochs=20 정도로 평가 출력까지 완주해 두고, 시간이 남을 때 EarlyStopping과 함께 늘려 다시 실행합니다.

Q6. 회귀인데 loss가 nan이면 무엇부터 봅니까? 답: 입력에 결측치가 남았는지 np.isnan(X_train_scaled).sum()으로 확인합니다. 결측 하나만 있어도 손실이 nan이 되고 이후 epoch에서 회복되지 않습니다.

Q7. 오류 메시지가 영어로 길게 나오면 어디를 읽습니까? 답: 처음부터 읽지 않고 incompatible, label value, expected shape 같은 키워드가 있는 줄을 찾습니다. 숫자 두 개(기대한 값과 실제 값)를 비교하면 대부분 원인이 드러납니다.
