## 자세히 보는 문항: Q5 IQR 이상치 제거

```python
q1 = df['production_units'].quantile(0.25)
q3 = df['production_units'].quantile(0.75)
iqr = q3 - q1
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr

df = df[(df['production_units'] >= lower) & (df['production_units'] <= upper)]
df = df.drop(columns=['record_id'])
df = df.reset_index(drop=True)
print(df.shape)   # (1969, 8)
```

채점에서 보는 것: 사분위수 `q1`, `q3` / IQR 계산 / 하한·상한 경계식 / 경계 안쪽 행만 유지 / `record_id` 제거

자주 틀리는 답:
- 경계 부호를 반대로 씀, 조건을 `|`로 연결해 필터가 무력화됨, `record_id` 대신 타깃을 제거
- 극단값 12개 외에 정상 분포의 양 끝 19개도 경계 밖이라 함께 제거되어 2000행이 1969행이 됩니다.

## 자세히 보는 문항: Q11 회귀 모델과 compile

```python
inputs = Input(shape=(X_train_scaled.shape[1],))
x = Dense(128, activation='relu')(inputs)
x = BatchNormalization()(x)
x = Dropout(0.2)(x)
x = Dense(64, activation='relu')(x)

model.compile(optimizer='adam', loss='mse', metrics=['mae'])
model.summary()
```

채점에서 보는 것: 입력층 / 첫 은닉층 relu / Dropout 층 / 출력층 노드 1개·활성화 없음 / `Model` 연결 / compile 설정

자주 틀리는 답:
- 회귀 출력에 `sigmoid`(출력이 0~1 범위로 제한됨), 분류용 loss와 accuracy, 출력 노드를 2로 설정
- `metrics=['mean_absolute_error']`로 쓰면 history 키가 달라져 Q13의 `mae`, `val_mae`와 어긋남, 손실을 `mse`가 아닌 `mae`로 지정

## 함께 풀기 — 답과 이유 (Q13)

## 함께 풀기 — 답과 이유 (Q14)

- `evaluate(X_test_scaled, y_test, verbose=0)`: 스케일링된 평가 데이터를 넣습니다. 반환값은 `[loss, mae]`이고 loss는 MSE입니다.
- `pred.flatten()`: `pred`는 (N, 1)이므로 (N,)로 폅니다.
- `mean_squared_error`: RMSE는 MSE의 제곱근이므로 `np.sqrt(mean_squared_error(y_test, y_pred))`입니다.
- `reindex(columns=X.columns, fill_value=0)`: 학습 컬럼 구성과 순서로 맞추고 없는 더미는 0입니다.
- `scaler.transform(new_df)`: 학습 때의 `scaler`를 재사용하며 `fit`하지 않습니다.
- `model.predict(new_scaled)`: 스케일링된 신규 샘플로 예측합니다.

---

## 정리

- 회귀는 출력층 `Dense(1)`(활성화 없음), 손실 `mse`, 지표 `mae`입니다. 분류용 `sigmoid`, `softmax`, `accuracy`를 쓰지 않습니다.
- 연속형 타깃에는 `stratify`를 쓰지 않습니다.
- 평가는 MAE, RMSE, R2이고, `pred`는 `flatten()`으로 1차원으로 만든 뒤 sklearn 지표에 넣습니다.
- 학습 곡선의 키 이름은 compile의 `metrics`가 정하므로 `mae`, `val_mae`를 씁니다.
- 신규 샘플은 `get_dummies`(`drop_first` 없이), `reindex`, `scaler.transform`, `predict` 순서입니다.
- 세 회차에서 반복된 실수 유형(재대입 누락, `fit` 위치, 신규 샘플 전처리)을 본인 기록에서 찾습니다.

## 예상 질문과 답 (1)

**Q1.** 회귀에서 `stratify`를 쓰면 어떻게 됩니까?
답: `energy_kwh`는 연속값이라 같은 값이 거의 없어 계층 분할을 시도하면 `ValueError`가 나거나 무의미합니다. 이 문항은 `stratify` 사용을 금지하는 규칙을 둡니다.

**Q2.** Q14에서는 왜 `drop_first=True`를 쓰지 않습니까?
답: 한 행짜리 샘플에서는 유일한 범주가 "첫 번째"라서 지워집니다. 그러면 입력한 `line_B`, `shift_night`가 사라져 기준 범주 조건으로 잘못 예측하므로, `get_dummies` 후 `reindex(fill_value=0)`로 학습 컬럼에 맞춥니다.

**Q3.** 회귀 출력층에 활성화 함수를 두면 왜 안 됩니까?
답: 에너지 사용량은 수백 kWh의 연속값인데 `sigmoid`나 `softmax`는 출력 범위를 제한합니다. `Dense(1)`은 기본이 선형 출력이라 어떤 실수값도 낼 수 있습니다.

## 예상 질문과 답 (2)

**Q4.** 머신러닝 문항은 스케일링하지 않은 데이터를 쓰는데 모의고사 1, 2회와 왜 다릅니까?
답: 트리 계열은 값의 대소 비교로 분기하므로 스케일링이 필요 없고, 이 회차 문항이 `X_train`, `X_test` 사용을 안내합니다. 어느 쪽이든 학습과 예측에 같은 종류의 데이터를 써야 하고, 문항 지시를 그대로 따릅니다.

**Q5.** Q5에서 이상치를 12개만 지웠는데 왜 31행이 줄어듭니까?
답: 극단값 12개 외에, 정상 분포의 양 끝 값 19개도 IQR 경계(약 288~713) 밖이라 함께 제거됩니다. 그래서 2000행이 1969행이 됩니다.

**Q6.** 학습 loss가 검증 loss보다 높게 나와도 과적합이 아닙니까?
답: 학습 `loss`는 Dropout이 켜진 상태에서 계산되므로 `val_loss`보다 높게 나올 수 있습니다. 검증 곡선이 상승으로 바뀌는지를 봅니다. 이 모범 답안에서는 val 곡선이 상승 전환하지 않아 심한 과적합 징후가 없었습니다.
