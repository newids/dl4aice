## 자세히 보는 문항: Q5 IQR 이상치 제거

```python
q1 = df['monthly_fee'].quantile(0.25)
q3 = df['monthly_fee'].quantile(0.75)
iqr = q3 - q1
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr

df = df[(df['monthly_fee'] >= lower) & (df['monthly_fee'] <= upper)]
df = df.drop(columns=['customer_id'])
print(df.shape)   # (2982, 7)
```

채점에서 보는 것: `q3 = 75% 분위수`, 하한~상한 범위 안의 행만 남겨 `df`에 재대입, `customer_id` 컬럼 제거

자주 틀리는 답:
- 3사분위수 자리에 중앙값(0.5)을 쓰거나, 조건을 뒤집어 이상치만 남겨 공집합이 됨
- `and`로 연결하거나 괄호를 빠뜨림, `drop` 결과를 재대입하지 않아 `customer_id`가 남음

## 자세히 보는 문항: Q7 분리와 스케일링

X = df.drop(columns=['churn'])

채점에서 보는 것: 7:3, `random_state=42`, 층화 추출 / 학습 데이터에만 `fit_transform` / 평가 데이터는 `transform`만

자주 틀리는 답:
- 평가 데이터에 `fit_transform`, `stratify` 누락, `test_size=0.7`로 학습과 평가를 뒤바꿈

## 자세히 보는 문항: Q14에서 자주 틀리는 답

- 새 샘플에 `fit_transform`: 한 건의 평균·표준편차를 새로 계산하므로 모든 값이 0이 됩니다.
- `fill_value` 누락: 없는 더미 컬럼이 NaN이 되어 예측이 `nan`입니다.
- `reindex`를 건너뜀: 한 건에는 `month`, `fiber` 더미만 생겨서 `scaler.transform`이 feature names 불일치 `ValueError`를 냅니다.
- 평가를 학습 데이터로 하거나 임계값을 지시와 다르게 지정합니다.
- 불리언 `[[True]]`를 그대로 출력합니다. 지문은 최종 판정 0 또는 1을 요구합니다.

순서: DataFrame 만들기, `get_dummies`, `reindex`, `scaler.transform`, `model.predict`

## 함께 풀기 — 답과 이유 (Q6)

```python
df = pd.get_dummies(df, columns=['contract_type', 'internet_service'], dtype=int)
```

- 대상 컬럼은 `contract_type`, `internet_service` 두 개입니다. `internet_service`를 빠뜨리면 문자열이 남습니다.
- `dtype=int`를 쓰지 않으면 더미가 True/False로 만들어집니다.
- 결과를 `df`에 다시 저장해야 합니다. 모범 답안 기준 출력은 (2982, 11)입니다.
- LabelEncoder로 0/1/2를 붙이면 없던 크기 관계를 학습하므로 채점 규칙이 금지합니다.

---

## 함께 풀기 — 답과 이유 (Q14)

- `evaluate(X_test_scaled, y_test, verbose=0)`: 스케일링된 평가 데이터와 정답을 넣습니다.
- `pred > 0.5`: 이진분류는 임계값 비교로 0/1을 만듭니다. `argmax`는 다중분류용입니다.
- `pd.DataFrame([new_data])`: 딕셔너리를 리스트로 감싸야 1행이 됩니다.
- `reindex(columns=X.columns, fill_value=0)`: 학습 때 컬럼 구성과 순서로 맞추고 없는 더미는 0입니다.
- `scaler.transform(new_df)`: 학습 때 만든 `scaler`를 재사용하며 `fit`하지 않습니다.
- `int(new_pred[0][0] > 0.5)`: 확률을 최종 판정 0 또는 1로 바꿉니다.

## 정리

- 인코딩은 분리 전에, 스케일링은 분리 후에 하고, `fit`은 학습 데이터에서만 합니다.
- 이진분류의 출력층은 `Dense(1, sigmoid)`이고 손실 함수는 `binary_crossentropy`입니다. 한쪽만 바꾸면 오류 없이 학습이 잘못됩니다.
- `fillna`, `drop`, `get_dummies`는 새 객체를 돌려주므로 재대입이 필요합니다.
- 콜백은 만든 뒤 `fit`의 `callbacks=[es, mc]`로 전달해야 동작합니다.
- 신규 샘플은 학습 때와 같은 전처리 순서를 거친 뒤 임계값 0.5로 판정합니다.
- 이탈 클래스의 recall(0.43)을 accuracy와 함께 봅니다.

## 예상 질문과 답 (1)

**Q1.** 분리 전에 결측치를 채우면 데이터 누수가 아닙니까?
답: 엄밀히는 대체값도 학습 데이터로만 구하는 것이 원칙입니다. 다만 이 시험 흐름은 Q7 분리 전에 전체 데이터로 처리하라고 지시하므로, 시험에서는 지시대로 전체 데이터에 적용합니다.

**Q2.** 이진분류에서 출력 노드를 2개로 두면 안 됩니까?
답: 이 모의고사의 채점 규칙은 `Dense(1, sigmoid)`와 `binary_crossentropy`의 짝을 요구하고, 노드 2개는 오답 사례로 등록되어 있습니다. 문항이 "이진분류에 맞는"이라고 쓰면 1개와 sigmoid로 답합니다.

**Q3.** 테스트 accuracy 0.7497이면 잘 나온 것입니까?
답: 평가 데이터의 유지(0)가 630건, 이탈(1)이 265건이라 전부 유지로 예측해도 약 70%입니다. 이탈 클래스의 recall이 0.43이므로, accuracy만 보고 판단하지 않고 `classification_report`를 함께 읽습니다.

## 예상 질문과 답 (2)

**Q4.** Q10 표에서 DecisionTree와 XGBoost의 accuracy와 f1이 같은데 복사한 것입니까?
답: 아닙니다. 이 데이터에서 우연히 지표가 같아진 것이며 두 모델의 예측이 서로 다른 행도 있습니다. 비교표에는 모델마다 자기 예측 변수를 넣어야 합니다.

**Q5.** 제 `epoch` 수가 모범 답안의 12와 다릅니다. 틀린 것입니까?
답: 중단 시점은 실행 환경과 난수에 따라 달라질 수 있습니다. `epochs=100`은 상한이므로 100보다 훨씬 앞에서 끝나면 `EarlyStopping`이 동작한 것입니다.

**Q6.** `metrics=['acc']`로 쓰면 왜 감점입니까?
답: Keras 3에서는 `history` 키가 `acc`, `val_acc`가 되어 Q13의 `accuracy`, `val_accuracy`와 어긋납니다. 지문이 `accuracy`를 지정하므로 그대로 씁니다.
