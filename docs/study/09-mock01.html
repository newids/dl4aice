자세히 보는 문항: Q5 IQR 이상치 제거

q1 = df['monthly_fee'].quantile(0.25)
q3 = df['monthly_fee'].quantile(0.75)
iqr = q3 - q1
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr

df = df[(df['monthly_fee'] >= lower) & (df['monthly_fee'] <= upper)]
df = df.drop(columns=['customer_id'])
print(df.shape)   # (2982, 7)

채점에서 보는 것: q3 = 75% 분위수, 하한~상한 범위 안의 행만 남겨 df에 재대입, customer_id 컬럼 제거

자주 틀리는 답: - 3사분위수 자리에 중앙값(0.5)을 쓰거나, 조건을 뒤집어 이상치만 남겨 공집합이 됨 - and로 연결하거나 괄호를 빠뜨림, drop 결과를 재대입하지 않아 customer_id가 남음

자세히 보는 문항: Q7 분리와 스케일링

X = df.drop(columns=['churn'])
y = df['churn']
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y)

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
print(X_train_scaled.shape, X_test_scaled.shape)
# (2087, 10) (895, 10)

채점에서 보는 것: 7:3, random_state=42, 층화 추출 / 학습 데이터에만 fit_transform / 평가 데이터는 transform만

자주 틀리는 답: - 평가 데이터에 fit_transform, stratify 누락, test_size=0.7로 학습과 평가를 뒤바꿈 - 문제는 "클래스 비율을 동일하게 유지"라고만 쓰고 stratify라는 단어를 쓰지 않습니다. Q2의 70:30 불균형이 그 이유입니다.

자세히 보는 문항: Q10 XGBoost와 세 모델 비교

자세히 보는 문항: Q11 모델 설계와 compile

model = Sequential()
model.add(Input(shape=(X_train_scaled.shape[1],)))
model.add(Dense(64, activation='relu'))
model.add(Dropout(0.3))
model.add(Dense(32, activation='relu'))
model.add(Dropout(0.3))

model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

채점에서 보는 것: Input의 shape=(특성 개수,) / 출력층 Dense(1, sigmoid) / compile adam, binary_crossentropy, accuracy

자주 틀리는 답: - 노드 1개에 softmax, 출력 노드 2개, 다중분류용 손실 함수 - 행 수를 shape로 사용(열 개수는 shape[1]), metrics=['acc']로 쓰면 Q13의 accuracy 키와 어긋남, metrics를 리스트로 감싸지 않음

자세히 보는 문항: Q12 콜백과 fit

es = EarlyStopping(monitor='val_loss', patience=5, restore_best_weights=True)
mc = ModelCheckpoint('best_model.keras', monitor='val_loss', save_best_only=True)

history = model.fit(X_train_scaled, y_train,
                    validation_split=0.2,
                    epochs=100, batch_size=32,
                    callbacks=[es, mc],
                    verbose=0)

print('실제로 학습한 epoch 수:', len(history.history['loss']))
# 12 (환경마다 다를 수 있음)

채점에서 보는 것: es(val_loss, patience=5, 최적 가중치 복원) / mc(best_model.keras, 가장 좋은 모델만 저장) / 검증 20%, epochs=100, batch_size=32 / callbacks 리스트

자주 틀리는 답: restore_best_weights 누락, callbacks를 fit에 전달하지 않음(오류 없이 100 epoch를 모두 돎), 확장자 없는 파일명

모범 답안 결과: test loss 0.4967, test accuracy 0.7497, 이탈 확률 0.8273, 예측 결과 1. 이탈(1) 클래스 recall은 0.43입니다.

채점에서 보는 것: 임계값 0.5로 0/1 변환 / 학습 컬럼 구성·순서로 맞추고 없는 컬럼은 0 / scaler로 transform만

자세히 보는 문항: Q14에서 자주 틀리는 답

  • 새 샘플에 fit_transform: 한 건의 평균·표준편차를 새로 계산하므로 모든 값이 0이 됩니다.
  • fill_value 누락: 없는 더미 컬럼이 NaN이 되어 예측이 nan입니다.
  • reindex를 건너뜀: 한 건에는 month, fiber 더미만 생겨서 scaler.transform이 feature names 불일치 ValueError를 냅니다.
  • 평가를 학습 데이터로 하거나 임계값을 지시와 다르게 지정합니다.
  • 불리언 [[True]]를 그대로 출력합니다. 지문은 최종 판정 0 또는 1을 요구합니다.

순서: DataFrame 만들기, get_dummies, reindex, scaler.transform, model.predict

정적 채점에서 주의할 점 (2분)

  • 사이트의 채점기는 코드를 실행하지 않습니다. 변수 이름과 핵심 인자가 있는지 검사합니다.
  • 따옴표 종류, 공백, 키워드 인자의 순서는 무시합니다.
  • 출력 결과는 보지 않으므로, 풀 때는 직접 실행해 결과를 확인합니다.
  • 옳은 답이어도 규칙이 다루지 않는 형태로 쓰면 오답으로 표시될 수 있습니다.

함께 풀기 — 답과 이유 (Q6)

df = pd.get_dummies(df, columns=['contract_type', 'internet_service'], dtype=int)
  • 대상 컬럼은 contract_type, internet_service 두 개입니다. internet_service를 빠뜨리면 문자열이 남습니다.
  • dtype=int를 쓰지 않으면 더미가 True/False로 만들어집니다.
  • 결과를 df에 다시 저장해야 합니다. 모범 답안 기준 출력은 (2982, 11)입니다.
  • LabelEncoder로 0/1/2를 붙이면 없던 크기 관계를 학습하므로 채점 규칙이 금지합니다.

함께 풀기 — 답과 이유 (Q14)

  • evaluate(X_test_scaled, y_test, verbose=0): 스케일링된 평가 데이터와 정답을 넣습니다.
  • pred > 0.5: 이진분류는 임계값 비교로 0/1을 만듭니다. argmax는 다중분류용입니다.
  • pd.DataFrame([new_data]): 딕셔너리를 리스트로 감싸야 1행이 됩니다.
  • reindex(columns=X.columns, fill_value=0): 학습 때 컬럼 구성과 순서로 맞추고 없는 더미는 0입니다.
  • scaler.transform(new_df): 학습 때 만든 scaler를 재사용하며 fit하지 않습니다.
  • int(new_pred[0][0] > 0.5): 확률을 최종 판정 0 또는 1로 바꿉니다.

정리

  • 인코딩은 분리 전에, 스케일링은 분리 후에 하고, fit은 학습 데이터에서만 합니다.
  • 이진분류의 출력층은 Dense(1, sigmoid)이고 손실 함수는 binary_crossentropy입니다. 한쪽만 바꾸면 오류 없이 학습이 잘못됩니다.
  • fillna, drop, get_dummies는 새 객체를 돌려주므로 재대입이 필요합니다.
  • 콜백은 만든 뒤 fit의 callbacks=[es, mc]로 전달해야 동작합니다.
  • 신규 샘플은 학습 때와 같은 전처리 순서를 거친 뒤 임계값 0.5로 판정합니다.
  • 이탈 클래스의 recall(0.43)을 accuracy와 함께 봅니다.

  3. 시간이 모자랄 때 어떤 문항부터 풀고 어떤 문항을 나중으로 미루겠습니까? 본인 점수 기록을 근거로 이유를 말해 봅시다.

예상 질문과 답 (1)

Q1. 분리 전에 결측치를 채우면 데이터 누수가 아닙니까? 답: 엄밀히는 대체값도 학습 데이터로만 구하는 것이 원칙입니다. 다만 이 시험 흐름은 Q7 분리 전에 전체 데이터로 처리하라고 지시하므로, 시험에서는 지시대로 전체 데이터에 적용합니다.

Q2. 이진분류에서 출력 노드를 2개로 두면 안 됩니까? 답: 이 모의고사의 채점 규칙은 Dense(1, sigmoid)와 binary_crossentropy의 짝을 요구하고, 노드 2개는 오답 사례로 등록되어 있습니다. 문항이 "이진분류에 맞는"이라고 쓰면 1개와 sigmoid로 답합니다.

Q3. 테스트 accuracy 0.7497이면 잘 나온 것입니까? 답: 평가 데이터의 유지(0)가 630건, 이탈(1)이 265건이라 전부 유지로 예측해도 약 70%입니다. 이탈 클래스의 recall이 0.43이므로, accuracy만 보고 판단하지 않고 classification_report를 함께 읽습니다.

예상 질문과 답 (2)

Q4. Q10 표에서 DecisionTree와 XGBoost의 accuracy와 f1이 같은데 복사한 것입니까? 답: 아닙니다. 이 데이터에서 우연히 지표가 같아진 것이며 두 모델의 예측이 서로 다른 행도 있습니다. 비교표에는 모델마다 자기 예측 변수를 넣어야 합니다.

Q5. 제 epoch 수가 모범 답안의 12와 다릅니다. 틀린 것입니까? 답: 중단 시점은 실행 환경과 난수에 따라 달라질 수 있습니다. epochs=100은 상한이므로 100보다 훨씬 앞에서 끝나면 EarlyStopping이 동작한 것입니다.

Q6. metrics=['acc']로 쓰면 왜 감점입니까? 답: Keras 3에서는 history 키가 acc, val_acc가 되어 Q13의 accuracy, val_accuracy와 어긋납니다. 지문이 accuracy를 지정하므로 그대로 씁니다.
